# Lumen Grid Labs (synthetic company)

Lumen Grid Labs, LLC is a fictional company created for grant-capture-agent development and evaluation. Every person, number, award and result in this folder is invented.

The `docs/` folder holds the evidence the Draft module may cite: a capability statement, five excerpts from past proposals, three project reports and four staff biographies. Email addresses use example.com and phone numbers use the reserved 555-01xx range, so redaction tests never touch real data.

The facts table in the M0 plan (task 9) is authoritative. If a document disagrees with it, fix the document. The corpus deliberately contains no past work in some topic areas, so evaluations can check that gaps are flagged and not invented.
