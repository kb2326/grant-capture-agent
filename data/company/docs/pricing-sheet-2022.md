## LGL-BMS2 Battery Management System

The LGL-BMS2 platform provides active cell balancing and real-time state estimation for high-voltage commercial lithium-ion battery enclosures. Hardware is sold as a modular architecture consisting of a primary master controller and distributed slave cell monitoring modules.

* **LGL-BMS2 Master Controller Unit (MCU):** $1,850 per unit  
  Includes CAN 2.0B bus interface, contactor control logic, isolation monitoring, and onboard data-logging module.
* **LGL-BMS2 Satellite Monitoring Board (SMB-16):** $285 per board  
  Provides voltage monitoring and thermistor inputs for 16 series-connected cells.
* **Current Shunt Sensor Subassembly (500A calibrated):** $420 per unit
* **LGL-BMS2 Developer Starter Kit:** $3,600  
  Includes 1 MCU, 4 SMB-16 boards, wiring breakout harnesses, desktop power supply, and software configuration tools.
