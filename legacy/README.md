# Legacy: v0 prototype

`v0-besi-prototype/` is the first version of this project, built in Nov–Dec 2025 while I was the sole AI engineer at BESI. It is kept for reference and comparison only. It is not maintained, not installed, and not part of the v1 build.

What v0 had: an ADK `LoopAgent` with Planner → Executor → Verifier prompts, live calls to Grants.gov / SBIR.gov / USAspending through OpenAPI specs, and a keyword-based eligibility check.

What v1 changes, and why, is documented in `docs/` at the repo root. The exact v0 snapshot is also available as the git tag `v0-besi-prototype`.

The company capability document v0 used was removed. v1 uses a fictional company profile instead.
